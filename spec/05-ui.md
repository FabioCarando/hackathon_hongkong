## 2. Files: "Everything the brain knows"

- Table: title · kind · supplier · status chip · pages · OCR method · last commit · used in (count).
- Filters: kind, supplier, status. Search box (F9) on top. Results show path + page + snippet.
- Detail panel on selection: page image(s) with a page selector, extracted fields with quotes, "Used in" list (click → History blame for that cell), linked decisions.

## 3. Memory: "What the brain expects"

- Two tabs:
  - **Expectations**, grouped by supplier/company: kind · key · value · tolerance · valid from/to · source chip · "learned from D-000x" badge.
  - **Decisions:** timeline of `decisions.jsonl` with who, when, answer badge (rejected/approved once/remembered), the reason in the user's words, the linked change set and commit.

## 4. History: "Every change and why"

- Commit timeline (newest first): date · author · subject · files changed. Seeded commits look the same as new ones.
- Select a commit → message body, changed cells with sources, decisions.
- **Blame box:** file · sheet · cell picker (default `forecast_2027_2028.xlsx › Forecast › C9`) → timeline of values with reason and source for each.

## 5. Ask: "Ask the brain"

- `st.chat_message` chat. Agent steps stream collapsed (`render_step`).
- Answer rendered sentence by sentence, each followed by source chips: `📄 lease p.3 §4` · `🔀 a1b2c3d` · `🧠 D-0003`. Chips open the doc page / commit / decision in an expander.
- Suggested questions as buttons: "Why is 2027 rent 82,400?" · "Why was the Shenzhen Parts invoice held?" · "Where is the signed lease?" · "Which contracts need action in the next 30 days?"

## Visual rules

- Status colours: 🔴 held, 🟡 needs approval/attention, 🟢 clean/entered, ⚪ tracked.
- Every number shown next to its source chip. No number without a source on screen.
- Plain language everywhere ("Price 8.3% above contract", not "PRICE-001 failed"). Control IDs in small grey text.
- Page images: render PDF pages with PyMuPDF at ~110 dpi for display. Cache them.
